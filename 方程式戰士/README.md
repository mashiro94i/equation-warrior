# 方程式戰士（Math Equation Warrior）

**v1.2** — 以數學函數彈道、微積分道具、畫筆與面積體為核心的 2D 平台射擊遊戲（Pygame）。關卡由 CSV／地圖編輯器驅動，支援水平捲動、地刺機關、鑰匙門與多種特殊敵人 AI。

> 本目錄為 GitHub 倉庫 [mashiro94i/equation-warrior](https://github.com/mashiro94i/equation-warrior) 內的 `方程式戰士/`。同倉庫另含 `kenny_assets/`（素材）、`map_editor/`（地圖編輯器）。

---

## 環境與執行

- **Python 3** + **Pygame**（開發時約 2.6.x）
- 在**本目錄**執行：

```powershell
cd 方程式戰士
python game.py
```

- 單元測試：

```powershell
cd 方程式戰士
python -m unittest discover -v
```

- **地圖**：優先讀 `../map_editor/map/level{N}.csv`（及 `level{N}_flip.csv` 等）；若無則用本專案 `map/`。
- **設定**：本機 `settings.json`（不入版控）儲存 BGM／音效音量與解析度；首次執行或無檔時 **BGM／音效皆預設 50%**（`core/settings_io.py`）。

## 操作總覽

| 按鍵／操作 | 功能 |
|-----------|------|
| `A` / `D` | 左右移動 |
| `W` | 跳躍 |
| `1` | **函數模式**：按住瞄準、放開發射（次方 0 播泡泡音、無彈） |
| `2` | **微分塊模式**：在可放置區內左鍵放置 `d/dx` 塊 |
| `3` | **積分模式**：左鍵優先對敵彈／畫筆做 **∫x/∫y**；否則在區內放置積分塊；**滾輪**切換 ∫x ↔ ∫y |
| `4` | **Sigmoid（S）**：游標附近持續嘗試把敵彈變治療彈 |
| `5` | **Sigma（Σ）**：按住左鍵蓄力，放開依排程發射數字彈 |
| `B` | **畫筆**；**450ms 內再按一次 `B`** → **面積拖曳**；拖曳後**放開左鍵**可沿甩動方向**投擲面積** |
| `Esc` | 遊戲中：暫停（設定／解析度／音量）；選單內：依頁面返回 |
| `R`（關卡中） | 重新載入目前關卡 |

暫停與主選單可調解析度、BGM／音效；全螢幕以 **letterbox** 維持 1600×900 邏輯座標。

**核心玩法（概念、微積分語意）** → **[核心玩法.md](./核心玩法.md)**  
**完整機制、數值、互動表** → **[具體遊戲玩法.md](./具體遊戲玩法.md)**  
**各怪物 GID、AI、代數與數值** → **[enemy.md](./enemy.md)**

## 版本重點（v1.2）

### 世界與關卡

- 邏輯解析度 **1600×900**；鏡頭捲動；**左／右邊界**修正避免卡邊。
- **各關模式不同**：關 1＝函數+積分+微分；關 2＝函數+畫筆／面積、微分需碰 **131417**；關 3＝函數+平方+根號+治療 S。
- **R** 整關重載；啟動預載關卡 CSV；選關時顯示載入畫面（減少首次進關卡頓）。
- 地刺、機關、鑰匙門、愛心、可破壞牆、重生點；`MAX_LEVEL = 3`。

### 戰鬥與道具

- 玩家 HP **200**；微分塊上限 **1**（滿不放）；積分塊上限 **3**（滿刪最舊）。
- 積分強化我方彈：放大、增傷、穿敵；積分塊可推靜止面積。
- 關卡 2：畫筆、雙 B 面積拖曳／投擲。

### 敵人

- 特殊怪：常數裝甲兵 65840、小數／虛數、e^x、sin 蝙蝠、巨像、65822 面積暴走等 → **[enemy.md](./enemy.md)**。
- 地圖 **131356** 為牆壁格（非敵人）；可踩敵人頭頂；**65840** 不跳躍、下落前避伸出地刺、掉鑰匙。

### 死亡與音效

- 死亡／暫停時停止全部 SFX；BGM 自 **`assets/audio/bgm/`** 隨機輪播。
- 詳見玩法文件「音效」與 **enemy.md**。

├── test_game.py
├── README.md
├── 具體遊戲玩法.md

同倉庫根目錄：

| 目錄 | 說明 |
|------|------|
| `kenny_assets/` | Kenney 圖塊包（玩家／敵人／UI 等） |
| `map_editor/` | 地圖編輯器；`map/*.csv` 為遊戲主要關卡來源 |

## CSV 圖塊編碼（摘要）

| 值 | 說明 |
|----|------|
| `-1` 或空白 | 空 |
| `0–8` | 實心障礙（legacy） |
| `9–10` | 水（碰到即死） |
| `15` / **66043** | 玩家出生／重生 |
| `16` / **65834、65838、65840…** | 敵人生成 |
| `19` / **65904** | 補血（愛心，**1/3** 最大血） |
| `20` / **65992、66019** | 出口 |
| **65850、65875、131356** | 牆（實心；131356 會渲染碰撞） |
| **13168、131368** | 可破壞牆 |
| **65935** | 地刺 |
| **65931** | 地刺機關 |
| **65880 / 65881** | 鑰匙／鑰匙門 |
| **65796** | 地圖內建面積格 |
| **65855 / 65856** | 地圖內建積分／微分塊 |

完整語意見 `core/tile_types.py` 與 **[具體遊戲玩法.md](./具體遊戲玩法.md)**。
