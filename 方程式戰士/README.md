# 方程式戰士（Math Equation Warrior）

**v1.1** — 以數學函數彈道、微積分道具、畫筆與面積體為核心的 2D 平台射擊遊戲（Pygame）。關卡由 CSV／地圖編輯器驅動，支援水平捲動、地刺機關、鑰匙門與多種敵人 AI。

> 本目錄為 GitHub 倉庫 [mashiro94i/equation-warrior](https://github.com/mashiro94i/equation-warrior) 內的 `方程式戰士/`。同倉庫另含 `kenny_assets/`（素材）、`map_editor/`（地圖編輯器）。

---

## 環境與執行

- **Python 3** + **Pygame**（開發時約 2.6.x）
- 在**本目錄**執行：

```powershell
cd 方程式戰士
python game.py
```

- 單元測試：

```powershell
cd 方程式戰士
python -m unittest discover -v
```

- **地圖**：優先讀 `../map_editor/map/level{N}.csv`（及 `level{N}_flip.csv` 等）；若無則用本專案 `map/`。
- **設定**：`settings.json` 儲存 BGM／音效音量與解析度，退出遊戲時寫回。

## 操作總覽

| 按鍵／操作 | 功能 |
|-----------|------|
| `A` / `D` | 左右移動 |
| `W` | 跳躍 |
| `1` | **函數模式**：按住瞄準、放開發射（次方 0 僅啵聲無彈） |
| `2` | **微分塊模式**：在可放置區內左鍵放置 `d/dx` 塊 |
| `3` | **積分模式**：左鍵優先對敵彈／畫筆做 **∫x/∫y**；否則在區內放置積分塊；**滾輪**切換 ∫x ↔ ∫y |
| `4` | **Sigmoid（S）**：游標附近持續嘗試把敵彈變治療彈 |
| `5` | **Sigma（Σ）**：按住左鍵蓄力，放開依排程發射數字彈 |
| `B` | **畫筆**；**450ms 內再按一次 `B`** → **面積拖曳**；拖曳後**放開左鍵**可沿甩動方向**投擲面積** |
| `Esc` | 遊戲中：暫停（設定／解析度／音量）；選單內：依頁面返回 |
| `R`（關卡中） | 重新載入目前關卡 |

暫停與主選單可調解析度、BGM／音效；全螢幕以 **letterbox** 維持 1600×900 邏輯座標。

**完整機制、數值、互動表** → **[具體遊戲玩法.md](./具體遊戲玩法.md)**

## 版本重點（v1.1）

### 世界與關卡

- 邏輯解析度 **1600×900**；鏡頭以玩家為錨（約螢幕 **1/4** 寬），`background_scroll` + `shift_world` 捲動整關（`world.world_length` 依 CSV 最寬列）。
- **地刺**：可穿過格子，**伸出時**踩住每 **1 秒**扣最大血量 **1/10**；**機關格**切換伸出／收回（`flip` 音效）。
- **機關觸發**：玩家、**面積體**、**積分塊**、**微分塊** 皆可碰機關切換地刺（離開後才可再觸發）。
- **鑰匙／鑰匙門**、**愛心**（回 **1/3** 最大血）、**可破壞牆**、**重生點**、多種 **Kenney 敵人格**。
- 關卡數：`MAX_LEVEL = 3`（可於 `constants.py` 調整）。

### 戰鬥與道具

- 可放置區：螢幕寬 **1/2**、全高，以玩家 **centerx** 為中心（貼邊夾在螢幕內）。
- 函數次方 `0～3`（三次尚未實作發射）；微分／積分／Sigmoid／Sigma／畫筆／面積拖曳與投擲。
- 面積體：mask 碰撞、擋敵彈、滑行傷害、積分下推、微分還原筆觸等。

### 敵人

- 一般敵：巡邏、視野內射擊；**65834** 衝刺近戰（約 1.2s 冷卻、單次扣血）；**65840** 死亡掉落鑰匙。
- **AI 會避開伸出中的地刺**（腳底探測）；僅**腳踩刺**才扣血，並嘗試橫向離開。
- 玩家可**踩在敵人頭上**；**65834** 不當玩家垂直實心牆（僅頭頂可站）。

### 死亡與音效

- 死亡：淡出 → **YOU DIED** → **復活**（整關 `reload_current_level()`，非僅傳送回重生點）。
- BGM `music2.mp3`；跳躍、發射、放塊、拾取、機關、墜落、破牆、玩家受傷／死亡、怪物攻擊等（見玩法文件「音效」）。

## 專案結構

```

├── game.py                 # 進入點
├── settings.json           # 音量／解析度（本機，可不入版控）

│   ├── constants.py        # 數值（血量、冷卻、放置區相關常數）
│   ├── soldier.py          # 玩家／敵人、地刺 AI、65834 衝刺
│   ├── world.py            # CSV、地刺、機關、鑰匙門
│   ├── game_audio.py       # assets/audio
│   ├── gameplay.py         # 放置區、Sigma、血量工具
│   ├── settings_io.py      # settings.json 讀寫
│   ├── tile_types.py       # 圖塊 GID 語意
│   ├── map_tile_loader.py
│   ├── calculus_blocks.py / brush.py / area_entity.py
│   ├── projectile.py / controller.py / interactions.py
│   └── …
├── assets/audio/           # wav／mp3
├── map/                    # 關卡 CSV 備援
├── test_game.py
├── README.md
├── 具體遊戲玩法.md
└── 遊戲特性.txt
```

同倉庫根目錄：

| 目錄 | 說明 |
|------|------|
| `kenny_assets/` | Kenney 圖塊包（玩家／敵人／UI 等） |
| `map_editor/` | 地圖編輯器；`map/*.csv` 為遊戲主要關卡來源 |

- **玩家外觀**：`kenney_tiny-dungeon` 的 `tile_0084` 等；缺檔時幾何 fallback。
- **尺寸**：`constants.py` 內 `TILE_SIZE_USER`、`PLAYER_VISUAL_SCALE`、`ENEMY_VISUAL_SCALE`。

## CSV 圖塊編碼（摘要）

| 值 | 說明 |
|----|------|
| `-1` 或空白 | 空 |
| `0–8` | 實心障礙（legacy） |
| `9–10` | 水（碰到即死） |
| `15` / **66043** | 玩家出生／重生 |
| `16` / **65834、65838、65840…** | 敵人生成 |
| `19` / **65904** | 補血（愛心，**1/3** 最大血） |
| `20` / **65992、66019** | 出口 |
| **65850、65875** | 牆 |
| **13168、131368** | 可破壞牆 |
| **65935** | 地刺 |
| **65931** | 地刺機關 |
| **65880 / 65881** | 鑰匙／鑰匙門 |
| **65796** | 地圖內建面積格 |
| **65855 / 65856** | 地圖內建積分／微分塊 |

完整語意見 `core/tile_types.py` 與 **[具體遊戲玩法.md](./具體遊戲玩法.md)**。
