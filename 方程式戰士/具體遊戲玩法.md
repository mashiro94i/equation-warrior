# 方程式戰士 — 具體遊戲玩法與系統說明（v1.1）

本文件整理 **目前版本** 所有模式、地圖機關、敵人 AI、音效、互動、數值，以及 **已修復／刻意保留的已知行為**（含 `遊戲特性.txt` 彩蛋）。與程式不一致處以程式為準。

---

## 一、遊戲目標與流程

| 項目 | 說明 |
|------|------|
| 主選單 | START、**設置**（解析度、BGM／音效、玩法簡述）、**關卡選擇**、EXIT |
| 進行中 | 擊殺敵人、抵達**出口**進下一關；`MAX_LEVEL` 目前為 **3**，通關後 **YOU WIN** |
| 水 | legacy `9–10` 或對應水格：碰撞即死 |
| 死亡 | 血量 ≤ 0 → 淡出 → **YOU DIED** → 按 **復活** → **`reload_current_level()`**（整關重置：敵人、塊、面積、捲動、地刺狀態等） |
| 重生點 | GID **66043**（亦相容 legacy `15`）；復活前鏡頭會對準重生點世界 X |
| 關卡重載 | 遊戲中按 **`R`** 或選單換關：捲動歸零後再對準玩家 |
| 設定持久化 | `settings.json`：BGM 音量、音效音量、解析度；退出時寫入（`settings_io`） |

## 二、畫面、鏡頭與座標

| 項目 | 說明 |
|------|------|
| 邏輯解析度 | **1600 × 900** |
| 實際視窗 | 全螢幕或視窗；**letterbox** 等比縮放，滑鼠映射回邏輯座標 |
| 玩家水平錨點 | 約螢幕寬 **1/4**；世界物件經 **`shift_world`** 捲動 |
| 捲動觸發 | 玩家接近左右緣（`SCROLL_THRESH`，隨解析度縮放）時更新 **`background_scroll`** |
| 關卡寬度 | `world.world_length` = CSV **最寬一列的欄數 × TILE_SIZE**，供捲動上限 |
| 瓦片 | `ROWS=16`、`COLS=20`（邏輯格參考）；`TILE_SIZE` 預設為螢幕高 ÷ `ROWS`，或以 `TILE_SIZE_USER` 覆寫 |

## 三、玩家狀態與物理

- **血量**：由 `constants.PLAYER_MAX_HP` 決定（顯示四捨五入至小數第 **2** 位）；調整難度請改常數。
- **移動**：重力、跳躍；與**地圖磚**、**面積 mask**、**存活敵人**碰撞。
- **踩在敵人頭上**：敵人頂緣可作站立面；**GID 65834** 對玩家**不作垂直實心阻擋**（僅頭頂落地），避免跳躍卡在其身體內。
- **敵人身體**：其他敵人／一般情況仍會在水平方向擋路。
- **螢幕頂**：`rect.top` 不可小於 0；撞頂向下反彈（`PLAYER_TOP_BOUNCE`）。
- **卡進地圖**：與磚重疊時 **僅對地圖** `_depenetrate_world_obstacles_only` 推出。
- **鑰匙**：拾取堆疊；HUD 顯示數量；與**鑰匙門**重疊消耗一把並移除該格障礙（`flip` 音效）。
- **長時間下墜**：約 **1 秒**以上空中且向下速度明顯時播放 **`fall.wav`**（每段墜落只播一次）。

## 四、地圖物件與機關

### 4.1 地刺（GID **65935**）

| 項目 | 說明 |
|------|------|
| 碰撞 | **不**進 `obstacle_list`；玩家／敵人／塊可**穿過該格** |
| 伸出狀態 | `world.spikes_extended == True` 時顯示並造成傷害 |
| 傷害 | 踩住期間每 **`SPIKE_DAMAGE_INTERVAL_MS`（1000 ms）** 扣 **最大血量 1/10**（至少對敵人保底 1 點） |
| 玩家 | 以**全身** `rect` 與刺傷害區相交判定 |
| 敵人 | 僅 **腳底帶**（約高 14px、左右內縮）判定；與避刺 AI **同一套** |
| 視覺 | 玩家**新碰**到刺格時該格圖像可**水平翻轉**（裝飾） |

### 4.2 地刺機關（GID **65931**）

- 碰一下：**伸出 ↔ 收回** 全關地刺（`toggle_spikes` + **`flip.wav`**）。
- **可觸發對象**：**玩家**、**面積體**、**積分塊**、**微分塊**（需與機關格 `colliderect`）。
- **閂鎖**：須**離開**機關格後才能再次觸發（`_switch_latch`）。

### 4.3 愛心（GID **65904**）

- 拾取回復 **最大血量 1/3**（`pickup` 音效），格位清除。

### 4.4 鑰匙與鑰匙門（**65880 / 65881**）

- 鑰匙拾取增加 `player.key_count`。
- 鑰匙門：玩家持有鑰匙且重疊（判定略放大）→ 消耗 1 把、移除門格與碰撞（`flip` 音效）。

### 4.5 可破壞牆（**13168、131368**）

- 面積**滑行**撞擊等可破壞；消失時 **`break.wav`**（音量約 45%）。

### 4.6 地圖內建塊與面積

| GID | 載入後 |
|-----|--------|
| **65796** | 面積體（淺藍填充樣式） |
| **65855** | 積分塊 |
| **65856** | 微分塊 |

## 五、模式一覽（`PlayerMode`）

| 模式 | 切換 | 摘要 |
|------|------|------|
| 函數 `FUNCTION` | `1` | 按住瞄準，放開發射 |
| 微分塊 `DERIVATIVE_BLOCK` | `2` | 可放置區內左鍵放塊 |
| 積分 `INTEGRAL_BLOCK` | `3` | 優先 ∫ 敵彈／畫筆；否則放積分塊；滾輪切軸 |
| Sigmoid `SIGMOID` | `4` | 游標附近轉化敵彈為治療彈 |
| Sigma `SIGMA` | `5` | 蓄力後排程發射 0…n |
| 畫筆 `BRUSH` | `B` | 可放置區內繪製 |
| 面積拖曳 `AREA_MOVE` | **450ms 內雙按 `B`** | 拖曳靜止面積；放開可**投擲** |

### 5.1 模式離開冷卻

| 模式 | 冷卻 |
|------|------|
| 微分塊 | 1000 ms |
| 積分塊 | 1000 ms |
| Sigmoid | 10000 ms |
| Sigma | 15000 ms |

函數、畫筆、面積拖曳：**無**離開冷卻。

### 5.2 可放置區

- **寬度**：螢幕 **1/2**；**高度**：全螢幕。
- **水平**：以玩家 **`centerx`** 為中心；超出左右邊界時**夾在螢幕內**。
- 微分／積分放塊、畫筆高亮、筆觸起點皆受此區限制（`placement_zone_around_player`）。

---

## 六、函數發射（模式 `1`）

- **次方** `0～3`：僅能靠微分塊 **−1**、積分塊 **+1** 調整。
- **次方 0**：不產生子彈（啵聲占位）。
- **次方 1**：直線彈；**次方 2**：拋物線（滑鼠為頂點）。
- **次方 3**：尚未實作瞄準／發射。
- 發射成功：**`shot.wav`**。

---

## 七、微分塊（模式 `2`）

| 項目 | 規則 |
|------|------|
| 上限 | 5；滿則移除最舊再放 |
| 外觀 | `d/dx` 分數線 |
| 物理 | 下落、堆疊；與積分塊相碰**互消** |

**互動：** 碰自己 −1 次方；碰敵人**定身**；碰敵彈／畫筆整筆／微分互消；碰**靜止面積**可還原為畫筆筆觸；與地圖僅**生成當下**重疊才清除。

放置：**`explosion.wav`**（`play_calculus_place`）。

---

## 八、積分（模式 `3`）

### 8.1 左鍵優先順序

1. 敵彈 **∫x/∫y** 加長（上限 `INTEGRAL_XY_EXTEND_MAX_PX`）。
2. 否則對**畫筆**積分（延長、閉環、平移面積等）。
3. 否則在可放置區放**積分塊**。

### 8.2 積分塊

- 上限 5；高度為微分塊 **3 倍**（∫x/∫y 字樣）。
- 碰自己 +1 次方；碰敵人**解除定身**；碰微分互消。
- 碰我方子彈：**放大＋增傷＋穿敵**（每敵只結算一次），**撞牆仍消失**。
- 碰**靜止面積**：面積被**往下推**（`fall` 等），**塊不消失**。

---

## 九、Sigmoid（模式 `4`）

- 游標旁 **S**；持續探測敵彈 → **綠色治療彈**（`sigmoid_heal_from_damage`）。
- 生效時 **`power_up.wav`**。

---

## 十、Sigma（模式 `5`）

- 按住左鍵每 **500 ms** 上界 +1（上限 10）；放開依排程發射 **0…n**。
- **彩蛋**：`n==0` 時改 **10 發 0 傷害** 再續後續數字。

---

## 十一、畫筆（`B`）與面積

### 11.1 畫筆

| 項目 | 數值 |
|------|------|
| 最多筆數 | 5 色 |
| 總長度上限 | 1800 px |
| 閉環 | 首尾近距或自交 → 自動閉合並**生成面積** |

### 11.2 面積體

- **mask** 碰撞；擋敵彈最多 **3** 發後碎裂（`break`）。
- 傷害由等效半徑映射 **50～500**。
- 我方子彈可推**滑行**；撞敵／磚消失。
- **微分**：還原筆觸；**積分塊**：下推。

### 11.3 面積拖曳與投擲

- **雙按 `B`（450ms）** 進入；拖曳靜止面積，與磚重疊則嘗試單軸或放棄。
- 若拖曳會把玩家推出邏輯螢幕 → **還原**該次拖曳。
- **放開左鍵**：游標位移夠大 → 沿方向**甩出**（`AREA_THROW_*` 常數），播放 **`shot.wav`**（`play_area_throw`）。

## 十二、敵人與子彈

### 12.1 共通

| 項目 | 說明 |
|------|------|
| 預設血量 | `ENEMY_DEFAULT_MAX_HP`（100）；單體可覆寫 |
| 子彈傷害 | `ENEMY_BULLET_DAMAGE`（100） |
| 受傷音效 | `assets/audio/player_take_damage/` 隨機（與玩家受傷同資料夾） |
| 死亡 | 播放死亡動畫後移除；**65840** 可掉落鑰匙 |

### 12.2 敵人種類（GID）

| GID | 行為摘要 |
|-----|----------|
| **65834** | 視野內**追擊**；週期性**向前衝刺**（約 18 幀、1.2s 冷卻）單次近戰傷害；**不射擊**；Kenney **65834↔65835** 雙幀步行 |
| **65838** | 一般敵；**65838↔65837** 動畫 |
| **65840** | 一般敵＋**死亡掉鑰匙**；**65840↔65841** 動畫 |
| **131449、131448** | 一般巡邏＋射擊 |
| **65835、65837、65841** | 僅動畫替換格，**不單獨生成**敵人 |

### 12.3 射擊型 AI

- 左右巡邏、隨機停頓；**視野**內停步射擊（`monster_attack` 隨機音效）。
- 懸崖探測：前方無地面則煞車／轉向。

### 12.4 地刺與敵人 AI

- 移動前以**腳底**預測下一步是否踩刺 → **不往刺上走**。
- 已踩在刺上：每幀嘗試**橫向離開**（`_try_step_off_spikes`）；巡邏／追擊時若腳在刺上會**轉向**。
- **扣血判定**：僅 `feet_on_spike_damage`；身體碰到刺尖但腳未踩中**不扣血**。

### 12.5 與微積分塊

- **微分塊**：敵人**定身**（不移動、不轉向）。
- **積分塊**：**解除定身**。

## 十五、特殊事件與彩蛋（`遊戲特性.txt`）

1. **面積底下吸附**：mask／地面對齊可能造成黏附感。  
2. **飛天魔毯**：雙 `B` 拖面積，站在上面像移動平台。  
3. **快速拖曳面積**：極限情況可能卡天花板或地板關係異常。

以上**刻意保留**，不當一般 Bug 修。
