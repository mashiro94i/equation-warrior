# 方程式戰士 — 具體遊戲玩法與系統說明（v1.0）

本文件整理 **目前版本** 所有模式、互動、數值、特殊事件，以及 **已修復／刻意保留的已知行為**（含 `遊戲特性.txt` 所列彩蛋）。與程式不一致處以程式為準。

---

## 一、遊戲目標與流程

- **主選單**：START、設置（解析度、BGM／音效）、EXIT；可顯示玩法簡述。
- **進行中**：通關卡、擊殺敵人、抵達出口（`tile 20`）進下一關；超過 `MAX_LEVEL`（目前 2）→ **YOU WIN**。
- **死亡**：血量 ≤ 0 → 死亡演出與重開。
- **水**：與水 tile 碰撞即死（沿用 CSV 規則）。

---

## 二、畫面、鏡頭與座標

| 項目 | 說明 |
|------|------|
| 邏輯解析度 | **1600 × 900**（`constants.SCREEN_WIDTH/HEIGHT`） |
| 實際視窗 | 可全螢幕或視窗；以 **letterbox** 等比縮放至視窗，滑鼠座標映射回邏輯座標 |
| 玩家水平錨點 | 約 **螢幕寬 1/4**；玩家 `centerx` 固定於此，世界（障礙、敵、彈、塊、面積、畫筆點等）整體 **shift** 造成捲動 |
| 瓦片 | `ROWS=16`、`COLS=20`，`TILE_SIZE = SCREEN_HEIGHT // ROWS` |

---

## 三、玩家狀態與物理

- **血量**：最大 `10.00`，運算／顯示四捨五入至小數第 **2** 位。
- **移動**：重力、跳躍、與 **地圖磚**、**面積體（mask）**、**存活敵人矩形** 碰撞。
- **踩在敵人頭上**：敵人 `rect` 頂緣可作為站立面；水平方向與敵人身體會擋路。
- **螢幕頂**：`rect.top` 不可小於 0；若往上撞頂會 **向下反彈**（速度係數見 `Soldier.PLAYER_TOP_BOUNCE`）。
- **卡進地圖**：若與磚重疊，有 **僅針對地圖磚** 的 depenetration（沿穿透較淺軸推出），減輕「頭頂先撞面積再與磚重疊」造成的卡死。

## 四、模式一覽（`PlayerMode`）

| 模式 | 切換方式 | 摘要 |
|------|------------|------|
| 函數圖形 `FUNCTION` | `1` | 按住 `1` 瞄準，放開發射 |
| 微分塊 `DERIVATIVE_BLOCK` | `2` | 可放置區內左鍵放塊 |
| 積分塊／∫xy `INTEGRAL_BLOCK` | `3` | 左鍵優先 ∫ 敵彈／畫筆；否則放積分塊；滾輪切軸 |
| Sigmoid `SIGMOID` | `4` | 游標附近持續嘗試轉化敵彈為治療彈 |
| Sigma `SIGMA` | `5` | 按住左鍵蓄力，放開排程發射 |
| 畫筆 `BRUSH` | `B` | 可放置區內繪製 |
| 面積拖曳 `AREA_MOVE` | **450ms 內連按兩次 `B`** | 拖曳 **靜止** 面積體 |

### 4.1 模式離開冷卻（`mode_cooldowns`）

離開後 **僅鎖同一模式**，在冷卻結束前無法再進入該模式：

| 模式 | 冷卻 |
|------|------|
| 微分塊 | **1000 ms** |
| 積分塊 | **1000 ms** |
| Sigmoid | **10000 ms** |
| Sigma | **15000 ms** |

函數、畫筆、面積拖曳：**無**此類離開冷卻。

## 五、函數發射（模式 `1`）

- **次方** `0～3`，僅能靠 **微分塊碰自己 −1**、**積分塊碰自己 +1**；邊界 0／3 時塊仍消耗並觸發邏輯，次方不越界。
- **次方 0**：只累計「啵」請求，**不產生子彈**（音效占位，未強制接 `mixer`）。
- **次方 1（線性）**：自機指向滑鼠的單位向量，等速直線（`MathProjectile.SPEED_PX`）。
- **次方 2（拋物線）**：滑鼠為頂點 `(h,k)`，過玩家，`a = -k/h²`；`|h|` 過小會 clamp。
- **次方 3**：顯示 TODO，**不進入瞄準**。
- **瞄準抗抖**：控制器內滑鼠量化（如 8px grid），減少數字與預覽跳動。

## 六、微分塊（模式 `2`）

| 項目 | 數值／規則 |
|------|------------|
| 可放置區 | 左 **2/3** 寬、全高 |
| 場上上限 | **5**；超過時 **移除最先放置的一塊** 再放新塊 |
| 外觀 | 小矩形上 **d／dx** 與分數橫線（非斜線字串） |
| 物理 | 下落、堆疊、與另一微分／積分塊相碰 **兩塊皆消失** |

**互動（塊通常會消失，除非另述）：**

- 碰 **自己**：次方 **−1**（邊界 0 仍觸發）。
- 碰 **敵人**：敵人 **定身**（不移動、不轉向），塊消失。
- 碰 **敵彈**：敵彈與塊皆消失。
- 碰 **積分塊**：兩塊互消。
- 碰 **畫筆**（線段／未完成筆觸）：**該色整筆** 與塊皆消失。
- 碰 **靜止面積體**：若面積有 `source_points`，**還原為畫筆筆觸**；面積與塊消失。
- 與 **地圖**：僅在 **生成當下** 若已與磚重疊則塊消失；落下後靠頂站立，不因「接觸磚側」整塊消失。

## 七、積分（模式 `3`）— 塊 + ∫x／∫y 合併

### 7.1 軸切換

- **滑鼠滾輪**：在積分模式下切換 **∫x ↔ ∫y**（函數瞄準中滾輪不改拋物線參數）。

### 7.2 左鍵優先順序

1. 對 **敵彈** 做 **∫x／∫y 加長**（有上限 `INTEGRAL_XY_EXTEND_MAX_PX` 等規則）。
2. 否則對 **畫筆** 做積分（延長／閉環面積／平移面積等，見畫筆與面積章節）。
3. 若都未命中，且點在 **可放置區** 內 → 放置 **積分塊**。

### 7.3 積分塊

| 項目 | 數值／規則 |
|------|------------|
| 上限 | **5**；已滿時再放會 **kill 最舊一塊** |
| 外觀 | 寬同微分塊、**高度為三倍** 以容納 **∫x／∫y** 字樣 |
| 物理 | 類似微分塊；與地圖僅 **生成當下** 重疊才清除 |

**互動：**

- 碰自己：次方 **+1**。
- 碰敵人：解除定身。
- 碰微分塊：互消。
- 碰畫筆：整色筆與塊消失，並依規則生成面積等。
- 碰 **我方數學彈（`MathProjectile`）**：塊消失，子彈 **放大**且傷害提高（各僅第一次，常數 `INTEGRAL_HIT_*`）；子彈獲 **穿敵**（每敵只結算一次傷害，不消失），**撞地圖磚仍消失**；與面積互動仍可能消耗子彈（推面積等）。
- 碰靜止面積：**面積被往下推**（給速度／路徑），**積分塊不消失**。

---

## 八、Sigmoid（模式 `4`）

- 游標旁顯示 **S**（大、置中於游標）。
- 模式開啟時 **持續** 以游標附近探測敵彈；命中後敵彈變 **綠色治療彈**（傷害公式 `sigmoid_heal_from_damage`，常數 `SIGMOID_HEAL_MAX`、`SIGMOID_ALPHA`）。
- 離開模式冷卻 **10 s**。

---

## 九、Sigma（模式 `5`）

- 游標旁顯示 **Σx**。
- **按住左鍵**：每 **500 ms** 上界 **+1**，上限 **10**。
- **放開**：上界 **無條件捨去** 得 `n`，排程發射 **0…n**（間隔 `SIGMA_FIRE_INTERVAL_MS`）。
- **彩蛋**：若最終 `n == 0`，**不發單發 0**，改為 **10 發 0 傷害**（間隔仍相同），之後若序列還有下一個數字再接續（見 `build_sigma_shot_schedule`）。
- 離開模式冷卻 **15 s**。

---

## 十、畫筆（`B`）與筆觸規則

| 項目 | 數值 |
|------|------|
| 可放置區 | 左 **2/3** 寬 |
| 最多筆數（色） | **5**（色盤依筆數 HSV 生成） |
| 總線段長度上限 | **1800 px** |
| 閉環 | 首尾距離或 **線段自交** 可自動閉合並裁掉多餘線段；閉環後 **返還** 已計入的長度 |

**與微積分：**

- 微分／積分塊碰到筆：**整色整筆** 清除（含未完成筆觸）。
- **閉環完成當下**：筆觸從畫筆列表移除，**自動** 以多邊形生成 **面積體**（不必再按積分對畫筆）。
- **非閉環** 被積分塊／∫ 點到：依 **∫y 向下、∫x 依玩家左右** 等規則轉成面積（含平移掃出、裁切地圖等實作）。

## 十一、面積體（`AreaBody`）

### 11.1 共通

- **碰撞**：與畫面一致之 **mask**；與磚、角色、子彈等依程式使用 `intersects_rect` 或專用邏輯。
- **擋敵彈**：最多 **3** 發；透明度隨層數變化，第三發後碎裂，**該發敵彈一併消失**。
- **傷害數字**：顯示於面積中央；數值由 **等效半徑／面積** 指數映射到 **50～500**（錨點見 `constants` 內 `AREA_DAMAGE_*`）。
- **滑行**：被我方數學彈命中可沿 **子彈軌跡** 或推方向移動；滑行中對敵造成傷害，撞 **敵人或磚** 消失（同幀規則以程式為準）。
- **靜止面積**：不主動做撞牆消失；可被 **微分**（變回線）、**積分塊**（下推，塊不消失）。

### 11.2 與地圖

- 多邊形／掃描面積生成時會 **裁掉與障礙重疊** 的像素，可能 **分裂** 成多個面積實體。

### 11.3 面積拖曳（`AREA_MOVE`）

- **進入**：**450 ms** 內連按兩次 `B`（`DOUBLE_B_AREA_MOVE_MS`）；單次 `B` 仍為畫筆。
- **操作**：左鍵點 **靜止** 面積後拖曳；以 **snapshot／restore** 嘗試位移；與磚重疊則改試僅 X 或僅 Y，都失敗則不動。
- **保護玩家**：若拖曳後面積與玩家相交，且將玩家矩形平移同位移會 **超出邏輯螢幕**，則 **還原該次拖曳**。
- 游標為 **黃色十字**；下方狀態列有說明文字。

## 十二、HUD 與介面

- **左上**：`HP`、各模式冷卻（函數、微分、積分、S、Σ 等列）。
- **下方狀態列**：置中顯示目前模式說明（函數次方、塊數量、Sigma 蓄力、畫筆剩餘長度、面積拖曳提示等）。
- **可放置模式**：左 2/3 區 **半透明框** 提示。
- **敵人**：頭上顯示 **HP: x.xx**。
- **暫停／選單設置**：模糊叠圖、解析度選項、音量滑桿。

## 十三、敵人與子彈

- **敵人子彈**：直線、`EnemyBullet.DAMAGE = 100`（一發即死級別，設計上靠機制生存）。
- **敵人 AI**：巡邏、隨機停頓、視野內停步射擊；可被微積分塊影響移動／轉向。

## 十四、特殊事件與彩蛋（`遊戲特性.txt`）

以下在文件中標為 **「特性／彩蛋，不當 Bug 修」**：

1. **角色碰到面積「底下」會被吸附**  
   - 與面積 mask、地面對齊、射線吸附等有關；可當作遊玩上的黏附感。

2. **「飛天魔毯」（雙 B）**  
   - 連按兩次 `B` 進入 **面積拖曳**；拖著面積移動時，若玩家站在面積上，視覺上可能像「搭著移動平台」。

3. **快速拖曳面積**  
   - 可能出現面積 **卡入天花板** 或與地板關係怪異的極限狀況（與每幀大步位移、只對磚做阻挡解析有關）；列為已知極限行為。

## 十五、已修復的問題（實作史摘要）

| 主題 | 說明 |
|------|------|
| 面積「站上去漂浮」 | 站立高度改用具 **mask 欄位掃描** 的 `surface_top_at_world_x`，不用外接矩形上緣 |
| 面積下方抖動／頭頂判定 | 撞面積底緣改用 `surface_bottom_at_world_x`；垂直合併解析減少多磚來回改寫 |
| 角色斜坡抖動 | 射線對齊、坡度微抬、單次垂直解析、側向碰撞裁高等 |
| 頭上既有面積邊跳邊卡磚 | 結尾加 **僅對地圖** 的 `_depenetrate_world_obstacles_only` |
| 積分與 3a/3b 敘述 | 操作合併在 `3`；放置區寬度改為 **2/3** |
| 狀態列 `status_rect` | 補回遺失變數定義 |
| 積分塊數／高度／與我方子彈 | 上限 5、積分塊圖示加高、碰彈放大＋穿敵＋撞牆仍死 |
| 畫筆閉環 | 自動成面積、裁線、長度返還 |
| 玩家錨定左側 | `player_anchor_x` + `shift_world` |
| 全螢幕比例 | 縮放與滑鼠映射 |
| 面積拖曳與玩家出界 | 位移後檢查 `player.rect.move(dx,dy)` 是否在螢幕內，否則 restore |
