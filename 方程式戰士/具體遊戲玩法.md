## 〇、數學語意：為何機制這樣設計

本作規則來自「把算式操作變成可玩動作」。下列說明**設計原因**（教學隱喻），細節數值仍以程式為準。

### 傷害與治療的符號

- 敵彈／敵人攻擊在程式裡對玩家是**扣血（負向 HP 變化）**，可記為負的「傷害量」**D**。
- **Sigmoid（S 模式）**：不直接改變彈道公式，而是對**已存在的敵彈**套用  
  **治療量 H = heal_max × σ(α·D)**（σ 為 logistic，把實數壓到 0～1 再放大）。  
  **D 為負**（傷害）時，經 σ 與常數係數可得到**正的 H** → 彈變**綠色治療彈**，命中玩家**加血**。  
  這就是「敵人的攻擊是負數，經 Sigmoid 變成正數治療」的實作理由。

### 微分塊

| 對象               | 為何                                                          |
| ------------------ | ------------------------------------------------------------- |
| **玩家**           | 對「函數次方」微分 → 次方 −1（最低 0，0 次只播啵、不發彈）    |
| **一般敵人**       | 敵移動視為線性／分段線性；微分 → **速度為 0、不轉向**（定身） |
| **敵彈**           | 線性彈道「被微分」→ **消失**                                  |
| **微分＋微分塊**   | 兩塊互碰 → 皆消失                                             |
| **靜止面積**       | 微分 → 還原成**筆線**（面積是積分結果，微分回去）             |
| **65840 純 99999** | **常數的微分為 0** → **即死**                                 |
| **65843 sin**      | 微分 → 標籤 sin→cos→−sin，並**俯衝**（相位突變）              |
| **e^x**            | d/dx e^x = e^x → **微積分塊無效**                             |

### 積分塊

| 對象         | 為何                                                    |
| ------------ | ------------------------------------------------------- |
| **玩家**     | 次方 +1                                                 |
| **一般敵人** | 解除定身                                                |
| **敵彈**     | 沿 ∫x／∫y **加長**、變大變強，可穿敵                    |
| **畫筆線**   | 非閉環：**整條平移**後填成面積；閉環：直接填滿          |
| **靜止面積** | 積分塊 → **往下推**（與子彈推面積同套力，方向固定向下） |
| **65840**    | 常數積分 → **99999x**，並**永久加速**                   |
| **65843**    | 積分 → 標籤相位反向（不俯衝）                           |

### 平方／根號（關卡 3）

| 對象       | 為何                                                  |
| ---------- | ----------------------------------------------------- |
| **65820**  | ² 小數更小（0.0001、難打、無敵）；√ 變大（0.1，好打） |
| **65823**  | √(−1)→**i** 穿牆；i²→**−1**                           |
| **131437** | √ 質量減半變快；² 質量加倍、壓扁玩家                  |

## 一、遊戲目標與流程

| 項目         | 說明                                                                                                                   |
| ------------ | ---------------------------------------------------------------------------------------------------------------------- |
| 主選單       | START、**設置**（解析度、BGM／音效、玩法簡述）、**關卡選擇**、EXIT                                                     |
| 啟動         | 選單底圖 → 載入資源 → **預載關卡 1～3 CSV**；**選關後** `init_level`（選關時顯示「載入關卡 n」）                       |
| 進行中       | 擊殺敵人、抵達**出口**進下一關；`MAX_LEVEL` 目前為 **3**，通關後 **YOU WIN**                                           |
| 水           | legacy `9–10` 或對應水格：碰撞即死                                                                                     |
| 死亡         | 血量 ≤ 0 → **先停止全部音效**（不含 BGM）→ 淡出 → **YOU DIED** → **復活** → `**reload_current_level()`\*\*（整關重置） |
| 重生點       | GID **66043**（亦相容 legacy `15`）；復活前鏡頭對準重生點世界 X                                                        |
| **關卡重載** | 遊戲中按 `**R`\*\*：等同整關重載（敵人、塊、面積、捲動、地刺、模式鎖等）                                               |
| 暫停 `Esc`   | 開啟暫停時 **停止全部音效**（不含 BGM）；可調解析度與音量                                                              |
| 設定持久化   | `settings.json`：BGM 音量、音效音量、解析度；退出時寫入                                                                |

## 八、微分塊

| 項目             | 規則                                                                           |
| ---------------- | ------------------------------------------------------------------------------ |
| **玩家放置上限** | **1** 塊（`DERIVATIVE_BLOCKS_MAX`）                                            |
| 滿了再放         | **失敗**（`CALC_DERIVATIVE_EVICT_OLDEST_WHEN_FULL = False`，**不**自動刪舊塊） |
| HUD 計數         | 僅 **玩家放置**；地圖內建 **65856** 不計                                       |

**為何（摘要）**

- **定身**：敵人移動在設計上當「對時間一次」的關係，微分後「速度」→0。
- **敵彈消失**：線性彈道被微分後不再存在。
- **碰自己降次方**：對玩家函數次方 −1。
- **常數 99999 微分即死**：見 [enemy.md](./enemy.md) 65840 節。

放置：`**explosion.wav`\*\*。

## 十、Sigmoid 與 Sigma

### Sigmoid（S 模式，關卡 3 按 `4` 切換）

| 項目         | 說明                                                                                                         |
| ------------ | ------------------------------------------------------------------------------------------------------------ |
| 作用對象     | 游標附近**敵方子彈**（非玩家發射的彈）                                                                       |
| 視覺         | 彈變**綠色**                                                                                                 |
| 數學理由     | 敵彈命中玩家時傷害為**負的 HP 變化**（負數）。套用 **logistic σ** 後得到**正治療量 H**，改為**加血**而非扣血 |
| 公式（程式） | **H = heal_max × σ(α × D)**，D 為該彈傷害值；σ 輸出介於 0～1                                                 |
| 與 65823     | **−1** 態敵人只吃**治療彈**傷害（實數子彈無效）；綠色 Sigmoid 彈可一擊秒殺                                   |

音效：`power_up.wav`；切換時中央提示「Sigmoid 治療模式／一般模式」。

### Sigma（按 `5` 蓄力發射）

| 項目     | 說明                                                                            |
| -------- | ------------------------------------------------------------------------------- |
| 數學理由 | 離散**求和** Σ：上界 **n** 時依序發射 **0, 1, 2, …, n** 的「數字彈」，傷害=數字 |
| 蓄力     | 按住每秒 +1，上限 10；放開後排程發射                                            |
| 彩蛋     | 僅當 **n=0**：連發 **10** 發「0」+ 泡泡音（與次方 0 的「啵」呼應）              |
| 一般     | **n>0** 時發 **0～n** 共 **n+1** 發，不展開成 10 發 0                           |

| `**enemy_hurt.wav`\*\*     | **敵人**受傷                                                      |
| `**bubble_pop.mp3`\*\*     | 次方 0 放開；Sigma **n=0** 連發期間循環（音量 **×2**）            |

| `**sin_wing_flap.wav**`    | sin 暈眩拍翅（約 40% 音量）                                       |
