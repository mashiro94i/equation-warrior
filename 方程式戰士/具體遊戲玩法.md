# 方程式戰士 — 具體遊戲玩法與系統說明（v1.2）

本文件整理 **目前版本** 所有模式、關卡限制、地圖機關、微積分規則、音效、互動、數值，以及 **已修復／刻意保留的已知行為**（含 `遊戲特性.txt` 彩蛋）。與程式不一致處以程式為準。

**各怪物 GID、AI、代數與數值詳解** → **[enemy.md](./enemy.md)**

---

## 一、遊戲目標與流程

| 項目 | 說明 |
|------|------|
| 主選單 | START、**設置**（解析度、BGM／音效、玩法簡述）、**關卡選擇**、EXIT |
| 啟動 | 選單底圖 → 載入資源 → **預載關卡 1～3 CSV**；**選關後** `init_level`（選關時顯示「載入關卡 n」） |
| 進行中 | 擊殺敵人、抵達**出口**進下一關；`MAX_LEVEL` 目前為 **3**，通關後 **YOU WIN** |
| 水 | legacy `9–10` 或對應水格：碰撞即死 |
| 死亡 | 血量 ≤ 0 → **先停止全部音效**（不含 BGM）→ 淡出 → **YOU DIED** → **復活** → **`reload_current_level()`**（整關重置） |
| 重生點 | GID **66043**（亦相容 legacy `15`）；復活前鏡頭對準重生點世界 X |
| **關卡重載** | 遊戲中按 **`R`**：等同整關重載（敵人、塊、面積、捲動、地刺、模式鎖等） |
| 暫停 `Esc` | 開啟暫停時 **停止全部音效**（不含 BGM）；可調解析度與音量 |
| 設定持久化 | `settings.json`：BGM 音量、音效音量、解析度；退出時寫入 |

## 二、畫面、鏡頭與座標

| 項目 | 說明 |
|------|------|
| 邏輯解析度 | **1600 × 900** |
| 實際視窗 | 全螢幕或視窗；**letterbox** 等比縮放，滑鼠映射回邏輯座標 |
| 玩家水平錨點 | 約螢幕寬 **1/4**；世界物件經 **`shift_world`** 捲動 |
| 捲動觸發 | 玩家接近左右緣（`SCROLL_THRESH`）時更新 **`background_scroll`** |
| 左邊界 | `background_scroll ≤ 0` 且玩家貼左螢幕邊時才限制往左；避免「捲到最左後無法再往左走」 |
| 右邊界 | `background_scroll` 達上限且玩家貼右螢幕邊時限制往右 |
| 關卡寬度 | `world.world_length` = CSV 最寬列 × `TILE_SIZE` |

## 三、玩家狀態與物理

| 項目 | 說明 |
|------|------|
| 最大血量 | **`PLAYER_MAX_HP` = 200**（HUD 顯示至小數第 2 位） |
| 移動 | 重力、跳躍；與地圖磚、面積 mask、存活敵人碰撞 |
| **踩在敵人頭上** | 橫向重疊 ≥ 寬 22%；腳底與敵頂距 **−8～14 px**；敵頂可作站立面，**不擋向上移動** |
| **65834** | 未踩頭時身體仍可能水平擋路；踩頭後與其他怪相同 |
| 螢幕頂 | `rect.top` 不可 < 0；撞頂反彈 |
| 鑰匙 | 拾取堆疊；與鑰匙門重疊消耗一把（`flip`） |
| 長時間下墜 | 約 1s 空中下墜播 **`fall.wav`**（每段一次） |
| **e^x 詛咒** | 被 **131449** 碰到後 **`integral_only_lock`**：只能 **積分模式**；中央提示；解除需重載關卡／死亡復活 |

## 四、關卡可用模式（`level_modes.py`）

各關**只能**使用下表模式；按未開放模式的數字鍵無效（詛咒鎖定時僅能積分）。

| 關卡 | 按鍵 | 可用模式 |
|------|------|----------|
| **1** | `1` | 函數 |
| | `2` | 積分塊 |
| | `3` | **微分塊**（關卡內建，**不需**碰地圖 131417） |
| **2** | `1` | 函數 |
| | `B` | 畫筆 |
| | 雙按 `B`（450ms） | 面積拖曳／投擲 |
| | `2` | 微分塊 — **預設不可用** |
| **2 解鎖微分** | 碰動畫格 **131417～131420** 任一 | 設 `derivative_round_unlocked`；提示按對應鍵（關卡 2 解鎖後為 **`2`**） |
| **3** | `1` | 函數 |
| | `2` | **平方塊** |
| | `3` | **根號塊** |
| | `4` | **切換治療 Sigmoid**（開／關） |

平方／根號塊：放置規則類似微積分塊，命中敵人觸發代數（見 **enemy.md** 巨人、0.01、-1 等）。

## 五、地圖物件與機關

### 5.1 地刺（GID **65935**）

| 項目 | 說明 |
|------|------|
| 碰撞 | 不進 `obstacle_list`；可穿過格子 |
| 伸出 | `world.spikes_extended` 時顯示並傷害 |
| 傷害 | 踩住每 **1000 ms** 扣 **最大血量 1/10** |
| 顯示／碰撞 | 格底向上約 **0.7 格**高；繪製與傷害區一致 |
| 玩家 | **腳底帶**與刺區相交 |
| 敵人 | 僅腳底帶判定；AI 避開伸出刺 |
| **99999 坦克** | 腳踩伸出刺 → **即死** |

### 5.2 地刺機關（GID **65931**）

- 玩家、**面積體**、**積分塊**、**微分塊** 可觸發；離開格後才能再拉（閂鎖）。

### 5.3 愛心、鑰匙門、可破壞牆、內建塊

與 v1.1 相同：**65904** 回 1/3 血；**65880/65881**；**13168/131368**；地圖 **65796** 面積、**65855** 積分、**65856** 微分（**不佔**玩家放置上限）。

### 5.4 微分解鎖動畫格

- 序列 GID：**131417 → 131418 → 131419 → 131420**（約 350ms 切換）。
- 玩家碰觸後格消失、本關微分解鎖（關卡 2 必要）。

## 六、模式一覽（`PlayerMode`）

| 模式 | 切換 | 摘要 |
|------|------|------|
| 函數 | `1`（若該關開放） | 按住瞄準，放開發射 |
| 微分塊 | `2` 或 `3`（依關卡） | 可放置區左鍵 |
| 積分 | 關卡 1 為 `2` | 優先 ∫ 敵彈／畫筆；否則放塊；滾輪 ∫x↔∫y |
| 平方／根號 | 關卡 3 的 `2`/`3` | 代數塊 |
| Sigmoid | 關卡 3 按 `4` 切換 | 游標附近敵彈→治療彈 |
| Sigma | `5` | 全關可用（若未遭模式鎖） |
| 畫筆／面積 | 關卡 2：`B`／雙 `B` | 見第十一節 |

### 6.1 模式離開冷卻

微分／積分 **1000 ms**；Sigmoid **10000 ms**；Sigma **15000 ms**。

### 6.2 可放置區

螢幕寬 **1/2**、全高，以玩家 **centerx** 為中心（貼邊夾在螢幕內）。

## 七、函數發射（模式 `1`）

- 次方 **0～3**：微分 −1、積分 +1（關卡 3 改由平方／根號塊影響敵人代數，不調玩家次方）。
- 次方 **0**：無彈；放開射擊播 **`bubble_pop.mp3`**（音量為音效設定 **×2**）；**3**：尚未實作。
- 發射：**`shot.wav`**。

## 八、微分塊

| 項目 | 規則 |
|------|------|
| **玩家放置上限** | **1** 塊（`DERIVATIVE_BLOCKS_MAX`） |
| 滿了再放 | **失敗**（`CALC_DERIVATIVE_EVICT_OLDEST_WHEN_FULL = False`，**不**自動刪舊塊） |
| HUD 計數 | 僅 **玩家放置**；地圖內建 **65856** 不計 |
| 互動 | 定身敵人；碰積分互消；碰靜止面積可還原筆觸；**65843 sin** 觸發俯衝 |

放置：**`explosion.wav`**。

## 九、積分

### 9.1 左鍵優先順序

1. 敵彈 ∫x/∫y 延長（上限 `INTEGRAL_XY_EXTEND_MAX_PX`）。
2. 畫筆積分（延長、閉環、平移面積）。
3. 可放置區放積分塊。

### 9.2 積分塊

| 項目 | 規則 |
|------|------|
| **玩家放置上限** | **3** 塊（`INTEGRAL_BLOCKS_MAX`） |
| 滿了再放 | **刪最舊**玩家塊再放（`CALC_INTEGRAL_EVICT_OLDEST_WHEN_FULL = True`） |
| 高度 | 微分塊的 **3 倍** |
| 碰敵人 | **解除定身** |
| 碰我方子彈 | **半徑 ×1.85、傷害 ×1.5**（僅首次）、**穿敵**（每敵結算一次）、**撞牆仍消失** |
| 碰靜止面積 | 面積**往下推**（`fall`），塊不消失 |

### 9.3 詛咒期

被 e^x 詛咒後只能操作積分模式（含 ∫ 敵彈／畫筆／放塊）。

## 十、Sigmoid 與 Sigma

- **Sigmoid**：關卡 3 按 `4` **開關**；游標旁敵彈→治療彈（`power_up.wav`）。**65823 -1** 僅治療彈可傷。
- **Sigma**：蓄力 0…n；`n==0` 時 **10 發 0** 並**循環泡泡音**（**×2** 音量）至排程射完。

---

## 十一、畫筆與面積（關卡 2）

- 畫筆：最多 5 色、總長 1800 px；閉環成面積。
- 面積：**mask** 碰撞；擋敵彈最多 3 發；我方子彈可推**滑行**；積分塊下推；微分還原筆觸。
- **雙按 B**：拖曳靜止面積；放開左鍵可**投擲**（`shot.wav`）。
- **65822**：視野內有**靜止面積**時暴走 14 發／輪（見 enemy.md）。
