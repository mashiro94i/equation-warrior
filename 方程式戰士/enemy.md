## 〇、設計原理：機制為何這樣做（數學語意）

本作把「算式操作」對應到「遊戲效果」。下列是**設計意圖**（教學隱喻），不是嚴格數學證明；程式用簡化規則實現。

### 玩家模式（與所有怪共用）

| 操作                      | 數學聯想                                             | 遊戲效果（為何）                                                                        |
| ------------------------- | ---------------------------------------------------- | --------------------------------------------------------------------------------------- |
| **微分塊 → 自己**         | 對多項式**降階**（次方 −1）                          | 彈道從拋物線變直線、再變常數；**0 次方**無彈道，只播「啵」彩蛋                          |
| **積分塊 → 自己**         | **升階**（次方 +1）                                  | 彈道更彎、更難控，換取更高次函數射擊                                                    |
| **微分塊 → 敵人（一般）** | 對「位移」求導 → **速度**；速度再導常為 0            | 敵人 AI 簡化為**直線速度為 0、不轉向**（`calc_frozen`）                                 |
| **積分塊 → 敵人（一般）** | 對運動狀態「積分」→ 恢復較完整運動                   | **解除定身**                                                                            |
| **微分塊 → 敵彈**         | 線性／常數彈道的導數更「簡單」                       | 子彈**消失**（線性彈道被微分掉）                                                        |
| **積分塊 → 敵彈**         | 沿飛行方向加長（∫x／∫y）                             | 子彈變大、變強，可**穿透敵人**（同一顆只算一次）                                        |
| **Sigmoid（S 模式）**     | 敵彈對玩家是**負的 HP 增量**；S 曲線把實數壓到 (0,1) | 先當成傷害量 **D**，算 **H = heal_max × σ(α·D)** 得**正治療量**，彈變綠、命中改**加血** |
| **Sigma**                 | 離散求和 **Σ**（0+1+2+…+n）                          | 依蓄力上界 **n** 排程射出整數傷害彈；**n=0** 時彩蛋連發「0」+ 泡泡音                    |
| **平方／根號（關卡 3）**  | 乘方、開方改變「數值大小」                           | 見下方各怪專節（小數、−1／i、巨人、常數坦克）                                           |

### 各怪物：為何用這些互動

| 怪物                 | 核心隱喻                             | 為何這樣變化                                                                            |
| -------------------- | ------------------------------------ | --------------------------------------------------------------------------------------- |
| **65820 小數幽浮**   | 小數 **平方變更小**、**根號變大**    | 誤打 **²** → 0.01²=0.0001，更小更難打、幾乎無敵；應打 **√** 放大到 0.1 再一般火力秒殺   |
| **65823 虛數幽靈**   | 負數開根號進**虛數**                 | **−1** 開 **√** → 標籤 **i**，穿牆騷擾（虛數不在實軸上）；**i²**=−1 回到 **−1** 實體態  |
| **65823 僅治療彈**   | 負數要用「非實數傷害」處理           | 一般實數子彈無效；**Sigmoid 轉成正治療**的綠彈可破 **−1**（一擊必殺）                   |
| **131437 巨人**      | 質量數 **256** 當 HP；√ 減半、² 加倍 | 連續 **√** 把「質量」開小變快變薄；**²** 質量暴增變牆，壓扁玩家                         |
| **131449 e^x**       | **e^x 微積分自己**（導／積還是 e^x） | **微積分塊對牠無效**；要用火力或近戰；碰玩家 → **只能積分模式**（詛咒：被「指數」污染） |
| **65840 常數裝甲兵** | **常數的微分 = 0**                   | **微分**純 **99999** → **死亡**；**積分** → **99999x**（常數變函數）→ 暴走              |
| **65843 sin 蝙蝠**   | 三角函數**導／積 = 相位推移**        | 微分：sin→cos→−sin；積分反向；並**俯衝**（相位突變）                                    |
| **65822 面積暴走**   | 靜止面積 = 「不隨時間變的區域」      | 優先轟面積；子彈打面積會消失（與打線性子彈不同）                                        |

更完整的流程與關卡限制 → **[具體遊戲玩法.md](./具體遊戲玩法.md)** 第二節起。

| 項目         | 值                                |
| ------------ | --------------------------------- |
| 預設最大血量 | **100**（`ENEMY_DEFAULT_MAX_HP`） |

| 死亡         | 動畫結束移除；`stop_enemy_sfx`    |

### 1.2 AI 啟動

- 一般敵：進視野後 **`_ai_activated` 永久為真**。
- **e^x（131449）**：在視野內即動；首次進視野播 `exp_enter.wav`。

### 1.3 踩在敵人頭上

橫向重疊 ≥ 寬 **22%**；腳底與敵頂 **−8～14 px** → 可當平台，不擋向上移動。

### 1.4 微積分／代數塊（共通）

| 對象   | 微分                                 | 積分     | 平方／根號（關卡 3） |
| ------ | ------------------------------------ | -------- | -------------------- |
| 一般敵 | 定身（速度→0、不轉向）               | 解定身   | —                    |
| 代數怪 | 見各節                               | 見各節   | 見各節               |
| e^x    | **免疫**（d/dx e^x = e^x，狀態不變） | **免疫** | 無效                 |

**一般敵定身原因**：敵人巡邏／追擊在程式裡是**分段常數或線性速度**；對「位移」做微分 → 速度；再微分 → 0，故用**凍結 AI 方向**表示「動不起來」。

## 六、65820 — 小數幽浮（0.01）

![65820](./docs/img/enemies/65820.png)

**定位**：體型極小、速度極快的發光微粒；HP 極低但難瞄準。

**為何這樣設計**

- 頭上 **0.01** 表示「很小的正數」。
- **平方 (²)**：小數平方**更小**（0.01² = 0.0001）→ 更難命中、設**無敵**、射更快，懲罰玩家亂用平方。
- **根號 (√)**：小數開根號**變大**（√0.01 = 0.1）→ 體型與速度回到一般怪，變成「終於打得到」的窗口，應改用一般子彈收尾。

| ------ | ------------------------------------------ |
| HP     | **0.01**                                   |
| 顯示   | `0.01`                                     |
| 體型   | `scale_mult` **0.1**                       |
| 速度   | ×**10**                                    |
| 射速   | `shoot_cd_mult` **1/3**（約 3 倍射擊頻率） |
| 透明度 | alpha 178                                  |
| 行為   | 高攻擊性追擊＋射擊                         |

| 目前標籤 | 操作     | 結果（程式）                                                          |

## 七、65823 — 虛數幽靈（-1 / i）

![65823](./docs/img/enemies/65823.png)

**定位**：實體負數敵人；根號誤擊會變成穿牆虛數騷擾型。

**為何這樣設計**

- **−1** 在實數軸上存在，但「對負數開根號」在實數內無解 → 遊戲裡用 **i（虛數）** 表示進入**穿牆、無視面積**的幽靈態。
- **i² = −1**：再平方回到 **−1** 實體態（關閉穿牆、恢復僅治療彈可傷）。
- **為何僅治療彈可傷 −1**：一般子彈代表「實數傷害」打實體負數；**Sigmoid** 把敵彈的**負傷害**經 logistic 映成**正治療量**（見具體玩法第十節），綠彈命中 **−1** 時視為「用對域」→ **秒殺**。

### 狀態 `-1`

| 項目       | 程式值                                                    |
| ---------- | --------------------------------------------------------- |
| HP         | 1                                                         |
| 透明度     | alpha **153**（約 40% 透明）                              |
| 傷害       | **僅治療彈**可傷（`only_heal_bullet_hurt`）；一般子彈無效 |
| 治療彈命中 | **即死**（`health = 0`）                                  |
| 穿牆       | 否                                                        |
| AI         | `neg_one` 高攻擊追擊                                      |

### 根號 → 狀態 `i`（虛數幽靈）

| 項目         | 程式值                                     |
| ------------ | ------------------------------------------ |
| 透明度       | alpha **178**                              |
| 穿牆／穿面積 | 是                                         |
| 移動         | `imaginary`：遠則靠近，近則繞圈            |
| 傷害         | 玩家 **5 格**內每 **1 s** 扣 **max_hp/20** |
| 一般子彈     | 可傷（不再僅限治療彈）                     |

### 平方（i → -1）

恢復 `-1` 態：關閉穿牆、alpha 153、僅治療彈可傷。

## 八、131437 — 臨界巨像（Threshold Colossus）

![131437](./docs/img/enemies/131437.png)

**定位**：慢速坦克；頭上顯示當前**質量數值**（程式為 HP 整數，初始 **256**）。隱喻 **x > 1** 的「大質量」門檻怪。

**為何這樣設計**

- **256 = 2⁸**：用「質量數」當血量，普通射擊像刮痧。
- **根號**：質量 **÷2**（HP 上限減半、體型縮小、變快）→ 連續開根號像 **256→128→64…**，從坦克變成好處理的中小怪。
- **平方**：質量 **×2**、體型變大變慢 → 變成**通道障礙**；玩家在變大範圍內會被**壓扁**（演出「被質量壓住」）。

| 項目      | 程式值    |
| --------- | --------- |
| HP / 標籤 | **256**   |
| 速度      | ×**0.25** |

### 平方

| 項目    | 程式值                                                                                       |
| ------- | -------------------------------------------------------------------------------------------- |
| 最大 HP | **×2**；當前 HP = `新max - 舊max + 舊HP`                                                     |
| 速度    | ×**0.5**                                                                                     |
| 體型    | ×**1.3**                                                                                     |
| 壓扁    | 變大瞬間玩家在擴大區 → **1.5 s** 扁平不可操作；**2.5 s** 後處死（`player_crush_kill_at_ms`） |
| 持續    | 平方態 **1.5 s** 後巨人還原 256                                                              |
| 音效    | `giant_crush.wav`                                                                            |

### 根號

| 項目    | 程式值             |
| ------- | ------------------ |
| 最大 HP | **×0.5**（至少 1） |
| 當前 HP | `max(新max, 舊HP)` |
| 速度    | ×**2**             |
| 體型    | **÷1.3**           |

> 連續根號可快速縮小「質量」與體型，從坦克變成高速小怪。

## 九、131449 — Exponential Ghost（e^x）

| 顯示         | **e^x**（上標 x）                                               |
| 透明度       | alpha **70%**                                                   |
| 穿牆／穿面積 | 是                                                              |
| 微積分       | **免疫**                                                        |
| 速度         | ×**1.1**                                                        |

## 十、65840 — 常數裝甲兵（99999）

![65840](./docs/img/enemies/65840.png)

**定位**：超高 HP、緩慢近戰；**微分即死**；**積分後絕對別讓它碰到積分塊**（變 99999x 並永久 ×10 速）。

**為何這樣設計**

- **常數函數 f(x)=C** 的導數 **f′(x)=0** → 對「純 99999」（無 x、無高次）施微分＝**歸零／死亡**。
- **積分**常數 → **Cx**（多一個 x）→ 從「不動的常數」變「會變的函數」，故積分後**永久加速**（教學：別對常數用積分）。
- 代數塊可再疊 **x 次方** 或 **99999 次方**（標籤用 ²、³ 顯示），但**只有微分純常數才即死**；踩地刺亦死（與「裝甲」對比脆弱點）。

| 項目        | 程式值                                                                        |
| ----------- | ----------------------------------------------------------------------------- |
| HP          | **99999**                                                                     |
| 速度        | ×**0.7**（積分加速後 **×10**）                                                |
| 近戰        | `melee_bump`（類 65834）                                                      |
| 死亡        | **掉落鑰匙**                                                                  |
| 踩伸出地刺  | **即死**                                                                      |
| 跳躍        | **不會**（台階跳、重疊分離跳皆關閉）                                          |
| 下落 1~2 格 | 僅 **`spikes_extended`** 時偵測；路徑或落點有刺則**不往下**（轉向／懸崖煞車） |

### 感測（以自身為中心）

## 十一、65843 — 三角函數蝙蝠（sin / cos）

![65843](./docs/img/enemies/65843.png)

**別名 GID**：**131448**、65844、65845 載入時皆視為 **65843**。

**定位**：正弦波飛行、難直瞄；微分／積分改**相位**並觸發**俯衝**；撞牆**暈眩**。

**為何這樣設計**

- 飛行軌跡用 **sin(x)** 聯想。
- **微分**：sin → cos → −sin（標籤循環），並**俯衝**（相位突變、軌跡錯位）。
- **積分**：相位**反向**一步（不俯衝），隱喻 ∫sin ∝ −cos 的相位差。
- 撞牆暈眩：軌跡被障礙截斷的懲罰。

| 項目       | 程式值                                 | future.txt 草案 |
| ---------- | -------------------------------------- | --------------- |
| HP         | **150**                                | 50              |
| 標籤循環   | sin(x)→cos(x)→-sin(x)                  | 同              |
| 水平速度   | ×**3**；左右 **3～6 格**正弦           | 同概念          |
| 垂直       | ×**2** 相位；振幅 **1～2 格**          | 同概念          |
| 與玩家距離 | 保持 **2～3 格**                       | 同              |
| 牆距       | 約 **0.3 格** margin 避牆              | 同              |
| 俯衝       | 微分塊觸發；**4 格**、×2 速、高度 ×0.5 | 草案寫 3 格     |
| 暈眩       | **5 s**、靠牆、拍翅音                  | 草案寫 3 s      |
| 攻擊       | 射擊＋`sin_attack.wav`                 | —               |

微分：相位 +1 並俯衝。積分：相位 −1（不俯衝）。
