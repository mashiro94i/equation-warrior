# 方程式戰士 — 敵人圖鑑與機制詳解

本文件以**目前程式**為準（`core/enemy_archetypes.py`、`core/enemy_special.py`、`core/soldier.py`、`core/tile_types.py`）。  
設計草案見 `future.txt`；若與程式不符，**以程式為準**（文末「與 future.txt 差異」表）。

## 一、共通規則

### 1.1 預設數值

| 項目 | 值 |
|------|-----|
| 預設最大血量 | **100**（`ENEMY_DEFAULT_MAX_HP`） |
| 子彈傷害 | **100** |
| 射擊冷卻基準 | **80 幀** × `shoot_cd_mult` |
| 受傷音 | `enemy_hurt.wav` |
| 死亡 | 動畫結束移除；`stop_enemy_sfx` |

### 1.2 AI 啟動

- 一般敵：進視野後 **`_ai_activated` 永久為真**。
- **e^x（131449）**：在視野內即動；首次進視野播 `exp_enter.wav`。

### 1.3 踩在敵人頭上

橫向重疊 ≥ 寬 **22%**；腳底與敵頂 **−8～14 px** → 可當平台，不擋向上移動。

### 1.4 微積分／代數塊（共通）

| 對象 | 微分 | 積分 | 平方／根號（關卡 3） |
|------|------|------|----------------------|
| 一般敵 | 定身 | 解定身 | — |
| 代數怪 | 見各節 | 見各節 | 見各節 |
| e^x | **免疫** | **免疫** | 無效 |

## 五、65822 — 面積暴走（優先攻擊面積）

**定位**：穿牆飛行；視野內有**靜止面積**時改為極大量射擊面積中心。

| 項目 | 程式值 |
|------|--------|
| HP | 75 |
| 透明度 | alpha **178**（約 30% 透明） |
| 穿牆／穿面積 | `ghost_walls`、`ghost_area` |
| 無面積時 | 直線朝玩家飛行（`ai_area_sprayer_chase`） |
| 暴走條件 | 視野 **16×12 格** 內有 `area.is_stationary()` |
| 每輪 | 冷卻 **70 ms**；**14 發**／輪，瞄準面積中心（抖動） |
| 子彈 vs 面積 | 擊中面積 → 子彈**消失**、`area.register_bullet_hit()`（面積累計命中，滿 **3** 次碎裂） |
| 音效 | `angry/*.wav` 隨機 |

面積消失或離開視野後，恢復追玩家。

## 六、65820 — 小數幽浮（0.01）

**定位**：體型極小、速度極快的發光微粒；HP 極低但難瞄準。必須理解**平方變更小、根號變大**。

| 項目 | 程式值 |
|------|--------|
| HP | **0.01** |
| 顯示 | `0.01` |
| 體型 | `scale_mult` **0.1** |
| 速度 | ×**10** |
| 射速 | `shoot_cd_mult` **1/3**（約 3 倍射擊頻率） |
| 透明度 | alpha 178 |
| 行為 | 高攻擊性追擊＋射擊 |

### 代數狀態（平方／根號塊，關卡 3）

| 目前標籤 | 操作 | 結果（程式） |
|----------|------|----------------|
| `0.01` | **根號** | → `0.1`；體型 **1.0**、速度 **×1**（變大變慢，易擊殺） |
| `0.01` | **平方** | → `0.0001`；**無敵** `invincible`；射速 **×5**（`shoot_cd_mult=1/5`） |
| `0.0001` | **根號** | → `0.01`（恢復小數態） |
| `0.1` | **根號** | → `0.01`（恢復極小高速態） |

> 設計語意：誤用平方會變得幾乎打不到；應用**根號**放大後再用普通火力解決。

## 七、65823 — 虛數幽靈（-1 / i）

**定位**：實體負數敵人；根號誤擊會變成穿牆虛數騷擾型。

### 狀態 `-1`

| 項目 | 程式值 |
|------|--------|
| HP | 1 |
| 透明度 | alpha **153**（約 40% 透明） |
| 傷害 | **僅治療彈**可傷（`only_heal_bullet_hurt`）；一般子彈無效 |
| 治療彈命中 | **即死**（`health = 0`） |
| 穿牆 | 否 |
| AI | `neg_one` 高攻擊追擊 |

### 根號 → 狀態 `i`（虛數幽靈）

| 項目 | 程式值 |
|------|--------|
| 透明度 | alpha **178** |
| 穿牆／穿面積 | 是 |
| 移動 | `imaginary`：遠則靠近，近則繞圈 |
| 傷害 | 玩家 **5 格**內每 **1 s** 扣 **max_hp/20** |
| 一般子彈 | 可傷（不再僅限治療彈） |

### 平方（i → -1）

恢復 `-1` 態：關閉穿牆、alpha 153、僅治療彈可傷。

## 八、131437 — 臨界巨像（Threshold Colossus）

**定位**：慢速坦克；頭上顯示當前**質量數值**（程式為 HP 整數，初始 **256**）。普通火力需配合**根號**縮小質量。

| 項目 | 程式值 |
|------|--------|
| HP / 標籤 | **256** |
| 速度 | ×**0.25** |

### 平方

| 項目 | 程式值 |
|------|--------|
| 最大 HP | **×2**；當前 HP = `新max - 舊max + 舊HP` |
| 速度 | ×**0.5** |
| 體型 | ×**1.3** |
| 壓扁 | 變大瞬間玩家在擴大區 → **1.5 s** 扁平不可操作；**2.5 s** 後處死（`player_crush_kill_at_ms`） |
| 持續 | 平方態 **1.5 s** 後巨人還原 256 |
| 音效 | `giant_crush.wav` |

### 根號

| 項目 | 程式值 |
|------|--------|
| 最大 HP | **×0.5**（至少 1） |
| 當前 HP | `max(新max, 舊HP)` |
| 速度 | ×**2** |
| 體型 | **÷1.3** |

> 連續根號可快速縮小「質量」與體型，從坦克變成高速小怪。

## 九、131449 — Exponential Ghost（e^x）

**定位**：微積分完全無效；須火力或近戰處理；碰到玩家施加**積分詛咒**。

| 項目 | 程式值 |
|------|--------|
| HP | **exp(5) ≈ 148.41** |
| 顯示 | **e^x**（上標 x） |
| 透明度 | alpha **70%** |
| 穿牆／穿面積 | 是 |
| 微積分 | **免疫** |
| 速度 | ×**1.1** |
| 移動 | 直線追玩家 + **近戰衝撞**（同 65834） |
| 碰玩家 | 怪消失；玩家 **`integral_only_lock`**；提示「只能使用積分模式」 |

## 十、65840 — 常數裝甲兵（99999）

**定位**：超高 HP、緩慢近戰；**微分即死**；**積分後絕對別讓它碰到積分塊**（變 99999x 並永久 ×10 速）。

| 項目 | 程式值 |
|------|--------|
| HP | **99999** |
| 速度 | ×**0.7**（積分加速後 **×10**） |
| 近戰 | `melee_bump`（類 65834） |
| 死亡 | **掉落鑰匙** |
| 踩伸出地刺 | **即死** |
| 跳躍 | **不會**（台階跳、重疊分離跳皆關閉） |
| 下落 1~2 格 | 僅 **`spikes_extended`** 時偵測；路徑或落點有刺則**不往下**（轉向／懸崖煞車） |

### 感測（以自身為中心）

左右各 **5 格**、上 **5**、下 **2**。

| 感測 | 行為（速度暫時 ×**2**，非 ×1.5） |
|------|----------------------------------|
| **微分塊** | 遠離；攻擊範圍內有微分則**不衝撞** |
| **積分塊** | 靠近（含從上方落下） |
| 無 | 恢復 ×0.7 |

### 代數（每次碰撞 ±1，100 ms 閘門）

| 操作 | 效果 |
|------|------|
| **積分** | 無 x → `99999x`；有 x → x 次方 +1；**永久** speed ×**10** |
| **微分** | 純 **`99999`** → **即死**；否則 x 次方 −1 |
| **平方／根號** | 調整 `base_exp`／`x_exp` 標籤（見 `enemy_special._calc_tank_algebra`） |

## 十一、65843 — 三角函數蝙蝠（sin / cos）

**別名 GID**：**131448**、65844、65845 載入時皆視為 **65843**。

**定位**：正弦波飛行、難直瞄；微分／積分改**相位**並觸發**俯衝**；撞牆**暈眩**。

| 項目 | 程式值 | future.txt 草案 |
|------|--------|-----------------|
| HP | **150** | 50 |
| 標籤循環 | sin(x)→cos(x)→-sin(x) | 同 |
| 水平速度 | ×**3**；左右 **3～6 格**正弦 | 同概念 |
| 垂直 | ×**2** 相位；振幅 **1～2 格** | 同概念 |
| 與玩家距離 | 保持 **2～3 格** | 同 |
| 牆距 | 約 **0.3 格** margin 避牆 | 同 |
| 俯衝 | 微分塊觸發；**4 格**、×2 速、高度 ×0.5 | 草案寫 3 格 |
| 暈眩 | **5 s**、靠牆、拍翅音 | 草案寫 3 s |
| 攻擊 | 射擊＋`sin_attack.wav` | — |

微分：相位 +1 並俯衝。積分：相位 −1（不俯衝）。
