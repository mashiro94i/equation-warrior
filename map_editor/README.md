# 地圖編輯器（Map Editor）

網格地圖編輯器，可繪製 tile、設定出生點與核心，存成 `level{N}.csv` 供主遊戲使用。

## 執行方式

```bash
python -m map_editor.run
```


## 介面說明

- **左側**：圖塊選單（Palette）
  - 空、地板、水、裝飾、出生 A/B、道具、核心等，固定大小、多欄排排站。
  - 點選圖塊後在右側地圖塗刷。
- **右側**：地圖網格
  - 左鍵塗刷、右鍵清除。
  - WASD / 方向鍵按住可連續捲動。
  - 滑鼠滾輪在地圖區可放大/縮小格線（Size）。
- **左下**：Level 的 + / -、Save、Load。
- **右下角面板**（貼齊螢幕底）：
  - **Cols**：-10、-、數值、+、+10 調整欄數。
  - **Rows**：-、數值、+ 調整列數。
  - **Size**：-、數值、+ 調整格線顯示比例。

## 存檔與載入

- 存檔路徑：`map_editor/map/level{N}.csv`（N 為目前 Level 數字）；翻轉狀態為同目錄 `level{N}_flip.csv`。
- 圖塊 PNG（可選）：`map_editor/img/tile/<id>.png`（id 與格內數字相同）；若無則用程式內建 placeholder。
- 若要給 **方程式戰士** 使用，可將 `level{N}.csv` 複製到 `方程式戰士/map/`（或沿用 `level{N}_data.csv` 檔名）；遊戲會優先讀 `level{N}.csv`。
